# 宏观房产数据表

截至 2026-09-28；覆盖20城，仓库累计187条观测（含历史、推导、区域代理和冲突值）。

本表是宏观数据底座，不构成当前买入城市排名。中心年毛租售比=1/中心房价租金比；原比值有舍入，不代表实际净收益。估值采用Numbeo非官方统一模型，当前主表所用版次：2026年中版、2026-05-27快照。

## 读取规则

- 核心比较/补充指标：最新可选记录；数值留空意味着缺口或未解决冲突。
- 原始观测保存在独立JSON/CSV中，保留期间、地域、计算链和来源；Excel仅保留核心比较、补充指标、数据源三个工作表。
- 数据源：采集方式与连接状态；网页检索可用不等于API已联通。
- 年度/普查数据保持原统计期；索引采集需要直连复核；空置类型不同不能排序。
- 新开工面积、竣工面积、竣工套数分列；人口总变动与净迁入分列。
- 区域按揭参考不是个人报价；缺少国家数据时保留代理标签。
